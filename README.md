# 星のちらばりじ / Hoshi no Chirabariji

A free design font inspired by constellations, shooting stars, and sparkling light.

## Free Version

This repository contains the free version of Hoshi no Chirabariji.
Includes Hiragana and Kanji, with approximately 1,214 characters in total.

Included:
- Hiragana
- Kanji
- Free-use character set included in this version

## Full Version

The full version includes additional characters such as:
- Katakana
- Latin alphabet
- Numbers
- Additional symbols

You can get the full version here:

https://vo8ov.booth.pm/items/1854583
